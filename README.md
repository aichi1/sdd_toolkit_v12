# AtCoder 学習教材

AtCoderレート向上のための体系的学習教材リポジトリ。
SDD（Spec-Driven Development）プロセスで自動生成。

## 使い方
1. このリポジトリでClaude Codeを起動
2. `/init-task` コマンドを実行
3. `/run-phase 1` から順に実行して教材を生成

## 構成
- `pre-docs/` — SDD設計書（教材仕様）
- `outputs/` — 生成された学習教材
  - `phase-01/week-01/lecture.md` — 学習解説
  - `phase-01/week-01/practice.md` — 練習問題
