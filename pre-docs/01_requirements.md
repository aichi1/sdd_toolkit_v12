# AtCoder 学習教材セット — 要件定義

## 概要

AtCoderレート向上を支援する体系的学習教材セットの自動生成プロジェクト。
殿（mebius37）が週次で学習を進めるための lecture.md（解説）と practice.md（練習）の
ペアを、Phase/Week構造で24週分生成する。

---

## ターゲットユーザー

- **対象者**: 殿（mebius37）
- **推定レート**: 800〜1100（茶〜緑境界）
- **目標**: 緑色（レート1200）到達
- **使用言語**: C++17 主力
- **学習スタイル**: 週次でlecture読解 → ABC問題で実践 → 復習

## lecture.md の構成要件

各week の lecture.md は以下の構成で作成する:

### 必須セクション

1. **トピック名・概要**
   - 当週のメインテーマ（例: 「累積和」「BFS」「DP入門」）
   - 1〜3文での概要説明

2. **なぜ重要か**
   - AtCoder での出現頻度・難易度帯との対応
   - 緑色達成に向けた重要度の説明

3. **概念の解説**
   - 図解的な説明（テキストで視覚的に表現）
   - 直感的な理解を助ける例え・比喩
   - 初心者にわかりやすい段階的説明

4. **アルゴリズム・実装**
   - 擬似コード または C++17 コード
   - コメント付きの実装例
   - 計算量（時間・空間）の分析

5. **典型的な適用パターン**
   - どのような問題文・条件でこのアルゴリズムを使うか
   - パターン認識のためのキーワード

6. **例題（1〜2問）**
   - 問題文（オリジナルまたはABC類似問題）
   - 考え方の解説（ネタバレ注意: 段階的ヒントを先出し）
   - C++17 実装コード + 詳細コメント
   - 計算量の確認

## practice.md の構成要件

各week の practice.md は以下の構成で作成する:

### 必須セクション

1. **推奨問題リスト**
   - ABC問題番号（例: ABC123-C）
   - 推定difficulty値（AtCoder Problems準拠）
   - AtCoder URL (https://atcoder.jp/contests/abc{N}/tasks/abc{N}_{alpha})
   - 各問題のカテゴリタグ
   - 難易度：★1〜★5 で表記

2. **各問題のヒント（段階的）**
   - Level 1: 方針の方向性のみ（アルゴリズム名は明かさない）
   - Level 2: 使うデータ構造・アルゴリズムのヒント
   - Level 3: 実装の骨格（コードの一部）

3. **模範解答**
   - C++17 コード（完全実装）
   - 行ごとの詳細コメント
   - なぜその実装になるのかの解説
   - 計算量・空間計算量の明記

4. **発展問題（余力がある場合）**
   - 同トピックのより難しい問題（difficulty +200〜400）
   - 簡単な解説方針のみ（詳細は省略可）

## 非機能要件

### NF-01: 難易度適切性
- Week 1〜8: difficulty 300〜700（灰〜茶後半）
- Week 9〜16: difficulty 500〜1000（茶〜緑前半）
- Week 17〜24: difficulty 800〜1200（緑安定化）
- 推奨問題は実在のABC問題（URLが有効であること）

### NF-02: コード品質
- C++17 準拠（#include <bits/stdc++.h> 使用可）
- コンパイル可能なコード（論理エラーなし）
- AtCoder 提出形式に準拠

### NF-03: 教材品質
- 説明は平易な日本語
- 段階的な難易度上昇（前weekの内容を踏まえた積み上げ）
- ネタバレ防止（ヒントは必ず段階式）

### NF-04: 自己完結性
- 各 lecture.md は単独で読める（前week参照なし）
- 各 practice.md の模範解答は完全実装

## 用語定義

| 用語 | 定義 |
|------|------|
| AC | Accepted（正解） |
| ABC | AtCoder Beginner Contest |
| difficulty | AtCoder Problemsが算出する問題難易度値 |
| レート帯 | 灰(~399)/茶(400-799)/緑(800-1199)/水(1200-1599)/青(1600+) |
| 典型90問 | E869120氏作成の教育的問題セット |
| lecture.md | 当週の学習解説ファイル |
| practice.md | 当週の練習問題・模範解答ファイル |
